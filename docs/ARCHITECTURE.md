# Архитектура и карта кода

## Компоненты и поток данных

`index.tsx` монтирует React-приложение. [App.tsx](../App.tsx) переключает видимость девяти экранов и оборачивает их в PromptProvider. Компоненты остаются смонтированы при переходах; их React-состояние сохраняется до перезагрузки страницы.

[services/geminiService.ts](../services/geminiService.ts) создаёт GoogleGenAI-клиент прямо в браузере. При отсутствии ключа ошибка возникает во время импорта. Это не серверный сервис, несмотря на имя каталога.

| Вызов | Модель в исходниках | Обработка |
| --- | --- | --- |
| getRealtimeStockData | gemini-3-flash-preview | Google Search, очистка ответа и JSON-разбор цены |
| getCompanyNews | gemini-3-pro-preview | Google Search, JSON-массив новостей, URL из grounding metadata |
| generateStockPrediction | gemini-3-pro-preview | Google Search, JSON-сценарии, стресс-тесты и rationale |
| generateReportSection | gemini-3-flash-preview | Текстовый абзац выбранного раздела |
| generatePresentationPoints | gemini-3-flash-preview | Текст тезисов; UI фильтрует строки с дефисом |

Названия моделей отражают конфигурацию кода, а не подтверждённую текущую доступность API.

BotSimulator сначала запрашивает цену, затем собирает промпт через `assemblePrompt`, вызывает генерацию и сохраняет результат в React-состоянии. UI вычисляет целевые цены сценариев из `closeAsOf` и процентов, но expectedClose и confidence принимает от модели.

Очистка JSON удаляет markdown и маркеры цитирования; затем применяется JSON.parse и преобразование значений. Строгая проверка типов, диапазонов, сумм вероятностей и соответствия источников не реализована. Источники прогноза сохраняются в объекте, но текущая карточка прогноза не отображает их отдельным списком.

## Состояние и внешние данные

- `context/PromptContext.tsx`: промпт сохраняется в localStorage под ключом `promptData`; он не является защищённым хранилищем.
- `constants.ts`: три тикера, учебные задачи и демонстрационные роли. Это не сведения о реальной команде и не подтверждение выполненных работ.
- Рыночные и прогнозные истории, чек-лист, роли и генерируемые тексты находятся в React-состоянии. Серверной базы данных нет.
- `index.html`: Tailwind загружается с CDN; также присутствует import map с внешними URL. Для демонстрации нужен интернет.
- `vite.config.ts`: env-значение GEMINI_API_KEY подставляется в process.env.API_KEY и process.env.GEMINI_API_KEY при сборке. Ключ оказывается доступен браузеру.
- `package.json`: dev, build и preview; отдельных test/lint-скриптов нет, lock-файл в исходном дереве отсутствует.

## Что потребуется для публичного продукта

Серверный API с хранением ключа и контролем запросов; авторизация; проверенный источник котировок и их времени; валидируемая схема ответов и URL; согласованный прогнозный горизонт; измерение качества и логирование без чувствительных данных. Telegram-интеграция, обученная модель и торговое исполнение требуют самостоятельной реализации.

Учебный Overview, checklist и генератор текста не являются доказательством существования этих подсистем.
