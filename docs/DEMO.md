# Демонстрация Oracle

## Подготовка

1. Запустите приложение локально по [README](../README.md) с отдельным ключом Gemini. Запросы расходуют квоту; не публикуйте сборку с ключом.
2. В Prompt Editor исправьте устаревший горизонт 2026-01-02, связанные календарные события и ограничения. Согласуйте Inputs Template с одной выбранной акцией; исходный шаблон смешивает одну акцию и корзину.
3. Не вводите клиентские секреты или непубличные финансовые сведения в промпт. Изменения сохраняются в localStorage этого браузера.
4. Объясните зрителю: это браузерный прототип. Название Telegram Trading Bot в учебном Overview описывает задание, а не работающий бот.

## Сценарий показа

| Шаг | Что показать | Что пояснить |
| --- | --- | --- |
| Market Pulse | Выберите META, GOOGL или MSFT и нажмите Fetch Data | Цена получена через модель с поиском; её нужно сверять с источником |
| News Intelligence | Запросите новости и откройте доступную ссылку | Ссылка из поисковых метаданных не гарантирует соответствие конкретному заголовку |
| Prompt Editor | Измените один раздел инструкции | Редактирование влияет на следующий запрос Bot Simulator |
| Bot Simulator | Нажмите Predict, рассмотрите сценарии и rationale | Прогноз и confidence не являются доказанными метриками качества |
| Task Checklist / Team Roles | Переключите задачу и отредактируйте демонстрационную роль | Это локальные учебные инструменты, без совместной работы и сохранения после refresh |
| Report Generator | Сгенерируйте один раздел | Текст — черновик; утверждения о внедрениях и валидации нужно проверять |
| Presentation Helper | Сгенерируйте тезисы | Вывод зависит от формата ответа: отображаются строки с начальным дефисом |

Не обещайте определённые котировки, прогнозы или новости: результат зависит от внешнего сервиса.

## Проверка после установки

- `npm run build` завершается; отдельно выполнена проверка `npx tsc --noEmit`.
- Приложение открывается на локальном адресе.
- При доступном ключе цена, новости и сценарный ответ обрабатываются без ошибки; источники проверены вручную.
- Редактирование промпта сохраняется после обновления страницы; Reset to Default возвращает исходный шаблон, включая его старые даты.
- История запросов, статусы задач и роли сбрасываются после обновления.
- Сбой API показывается как ошибка, а не как подтверждённый аналитический результат.

## Скриншоты

Готовых скриншотов в исходном дереве нет. После локального запуска уместны снимки Market Pulse, сценарной таблицы и Prompt Editor. Не включайте env-файлы, ключи, консоль разработчика или личные вкладки. Подписывайте AI-результаты как пример, с датой демонстрации; изображение не подтверждает точность модели.

## Статус проверки документации

Возможности и ограничения сверены с исходниками. На Node.js 24.15.0 выполнены `npm install --ignore-scripts --no-audit --no-fund`, `npm run build` и `npx tsc --noEmit`: сборка и проверка типов завершились успешно. Vite предупредил о размере основного JS-файла больше 500 kB; установка сообщила о deprecated node-domexception. Это не проверка уязвимостей зависимостей. Ключ Gemini не задавался; браузерная демонстрация и реальные API-вызовы не выполнялись. Проверочные пункты интерфейса выше остаются для последующего ручного прогона.
