# Безопасность прототипа

## Критичное ограничение: ключ в браузере

[vite.config.ts](vite.config.ts) подставляет GEMINI_API_KEY в клиентский код, а [geminiService.ts](services/geminiService.ts) создаёт SDK-клиент в браузере. Ключ из `.env.local` попадёт в сборку и запросы браузера. Gitignore предотвращает случайное добавление env-файла, но не делает опубликованный сайт безопасным.

Используйте прототип только для локального показа с отдельным ограниченным ключом, контролируйте квоту и завершайте демонстрацию отзывом ненужного ключа. **До публичного размещения перенесите вызовы Gemini на сервер** с защищённым хранением ключа, контролем доступа и ограничением запросов. Настройки развёртывания текущий код не обеспечивает.

Команда из README привязывает dev-сервер к 127.0.0.1; конфигурация по умолчанию слушает 0.0.0.0.

## Данные и недоверенный вывод

- Тикеры, собранный промпт и инструкции генерации отправляются в Gemini. Не добавляйте непубличные сведения клиента.
- Промпт сохраняется в localStorage и может быть прочитан скриптами того же origin и пользователями браузерного профиля. Это не хранилище секретов.
- В коде нет аутентификации, ролей, серверной базы и лимитов запросов приложения.
- Ответы модели могут содержать неверные сведения и ссылки. URL новостей не проходят строгую проверку протокола/домена. Перед публичным запуском валидируйте ссылки и структуру ответа; для демонстрации проверяйте источники вручную.
- Страница использует внешние ресурсы из index.html, включая Tailwind CDN. Для production нужна отдельная оценка внешних зависимостей и сборки.
- Финансовые сценарии, вероятности и confidence не прошли подтверждённую оценку качества. Не представляйте их как гарантии доходности или готовое основание для торговых операций.

## При обнаружении утечки

Отзовите/замените ключ у провайдера. Уберите доступ к опубликованной сборке и пересоберите приложение после переноса ключа на сервер. Удаление строки из git не отзывает ключ.

Не публикуйте секрет в issue. Передайте автору через согласованный приватный канал путь и безопасное описание проблемы; приватный канал в репозитории пока не указан. Очистку истории следует согласовывать отдельно.
